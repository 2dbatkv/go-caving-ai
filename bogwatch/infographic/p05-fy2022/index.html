What the IRS has

There is no NSS return for the fiscal year ending March 2022 in the IRS e-file index for any year from 2019 to 2026, on the IRS copies-of-returns page (read 23 September 2026), or on ProPublica. The Foundation's return for the same year is in the index. E-filing has been mandatory for tax years beginning after 1 July 2020, so a filed return would appear there.

The FY2023 return's "prior year" column repeats FY2021 exactly (revenue $2,382,898; expenses $448,401), which is the last return actually filed. The June 2022 figures come from text recognition of a scanned report (S-T-2206) and are unaudited; they should be checked against the original.

Why it is an issue

Basis D (outside requirement): an annual return is required and none is on record for this year. Basis C (statement versus record): reports describing returns as "completed" or "done" are not consistent with the IRS record. Basis E: the change in net assets for the year is reported on no public return.

What would settle it

IRS Form 4506-A asks the IRS for a copy of a named year's return; the IRS sends it or reports that none is on file. Anyone may file it.
